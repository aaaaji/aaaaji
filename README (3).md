## 🎮 Proyek GameAtlas-Flutter

**GameAtlas** adalah aplikasi katalog informasi game yang dikembangkan menggunakan Flutter. Aplikasi ini menyediakan halaman beranda, daftar game, dan detail game, serta fitur pencarian dan filter kategori. Data game disimpan sementara dalam file JSON lokal; gambar sampul ditampilkan melalui URL gambar daring.
